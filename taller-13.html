Taller Sesión 13: Lista de Tareas Dinámica con JavaScript

Objetivo del Taller

Crear desde cero una aplicación de lista de tareas completamente funcional utilizando HTML, CSS y JavaScript. Este proyecto integra todos los conocimientos de las sesiones anteriores.

Conocimientos Previos Necesarios

  • HTML básico (etiquetas, formularios, inputs)
  • CSS (selectores, estilos, clases)
  • JavaScript básico (variables, funciones, condicionales)
  • Manipulación del DOM (querySelector, addEventListener)
  • Eventos (click, submit, input)
  • Arrays (push, filter, forEach, find)
  • Objetos básicos

Lo que Vamos a Construir

Características de la Aplicación:

  1. Agregar nuevas tareas con prioridades (Alta, Media, Baja)
  2. Marcar tareas como completadas
  3. Eliminar tareas individuales
  4. EDITAR tareas existentes (nueva funcionalidad)
  5. Filtrar tareas (Todas / Activas / Completadas)
  6. Contador de tareas pendientes
  7. Limpiar todas las tareas completadas
  8. Persistencia de datos (LocalStorage)
  9. Interfaz moderna con etiquetas de prioridad
  10. Diseño responsive

Estructura del Proyecto

Vamos a crear 3 archivos:

taller-lista-tareas/
├── index.html
├── styles.css
└── app.js

3.3 - Función para Crear una Tarea

/**
 * Crea un objeto tarea nueva
 * @param {string} texto - Texto de la tarea
 * @param {string} prioridad - Prioridad de la tarea (alta, media, baja)
 * @returns {object} - Objeto tarea
 */
function crearTarea(texto, prioridad = 'media') {
  return {
    id: generarId(),
    texto: texto,
    prioridad: prioridad,
    completada: false,
    fechaCreacion: new Date().toISOString()
  };
}

Explicación:

  • Recibe el texto que el usuario escribió y la prioridad
  • Devuelve un objeto con 5 propiedades:
    • id: identificador único
    • texto: lo que hay que hacer
    • prioridad: nivel de prioridad (alta, media, baja)
    • completada: si está hecha o no (inicia en false)
    • fechaCreacion: cuándo se creó la tarea

/**
 * Agrega una tarea al array de tareas
 * @param {string} texto - Texto de la tarea

function agregarTarea(texto, prioridad) {

Explicación paso a paso:

  4. Actualizamos la vista
  5. Limpiamos el input y le damos foco

3.5 - Función para Renderizar (Mostrar) las Tareas

/**
 * Renderiza las tareas en el DOM según el filtro actual
 */
function renderizarTareas() {
  // Limpiar la lista actual
  listaTareas.innerHTML = '';

  // Filtrar las tareas según el filtro activo
  const tareasFiltradas = filtrarTareas();

  // Si no hay tareas, mostrar mensaje
  if (tareasFiltradas.length === 0) {
    listaTareas.innerHTML = '<li style="text-align: center; padding: 20px; color: #999;">No hay tareas aquí 😊</li>';
    return;
  }

  // Crear un elemento HTML para cada tarea
  tareasFiltradas.forEach(tarea => {
    const li = crearElementoTarea(tarea);
    listaTareas.appendChild(li);
  });
}

Explicación:

  • innerHTML = '' borra todo lo que había
  • filtrarTareas() devuelve solo las tareas que corresponden al filtro
  • Si no hay tareas, mostramos un mensaje amigable
  • forEach recorre cada tarea y crea su HTML
  • appendChild agrega cada tarea a la lista

3.6 - Función para Crear el HTML de una Tarea

/**
 * Crea el elemento HTML de una tarea
 * @param {object} tarea - Objeto tarea
 * @returns {HTMLElement} - Elemento <li>
 */
function crearElementoTarea(tarea) {
  // Crear el elemento <li>
  const li = document.createElement('li');
  li.className = 'tarea';

  // Si está completada, agregar la clase
  if (tarea.completada) {
    li.classList.add('completada');
  }

  // Crear el checkbox
  const checkbox = document.createElement('input');
  checkbox.type = 'checkbox';
  checkbox.checked = tarea.completada;
  checkbox.addEventListener('change', function() {
    toggleCompletada(tarea.id);
  });

  // Crear el span con el texto
  const span = document.createElement('span');
  span.className = 'tarea-texto';
  span.textContent = tarea.texto;

  // Crear la etiqueta de prioridad
  const etiquetaPrioridad = document.createElement('span');
  const prioridad = tarea.prioridad || 'media'; // Valor por defecto si no existe
  etiquetaPrioridad.className = `prioridad ${prioridad}`;
  etiquetaPrioridad.textContent = prioridad.toUpperCase();

  // Crear contenedor de botones
  const contenedorBotones = document.createElement('div');
  contenedorBotones.className = 'contenedor-botones';

  // Crear el botón de editar
  const btnEditar = document.createElement('button');
  btnEditar.className = 'btn-accion btn-editar';
  btnEditar.innerHTML = '✏️';
  btnEditar.title = 'Editar tarea';
  btnEditar.addEventListener('click', function() {
    editarTarea(tarea.id);
  });

  // Crear el botón de eliminar
  const btnEliminar = document.createElement('button');
  btnEliminar.className = 'btn-accion btn-eliminar';
  btnEliminar.innerHTML = '🗑️';
  btnEliminar.title = 'Eliminar tarea';
  btnEliminar.addEventListener('click', function() {
    eliminarTarea(tarea.id);
  });

  // Ensamblar contenedor de botones
  contenedorBotones.appendChild(btnEditar);
  contenedorBotones.appendChild(btnEliminar);

  // Ensamblar todo
  li.appendChild(checkbox);
  li.appendChild(span);
  li.appendChild(etiquetaPrioridad);
  li.appendChild(contenedorBotones);

  return li;
}

Explicación detallada:

  1. createElement('li') crea un elemento <li> en memoria
  2. Le asignamos la clase tarea
  3. Si está completada, agregamos la clase completada para los estilos
  4. Creamos el checkbox y le damos evento para marcar/desmarcar
  5. Creamos el span con el texto de la tarea
  6. Creamos el botón eliminar con su evento
  7. Unimos todo con appendChild

PAUSA: Dibuja en la pizarra:

li (tarea)
├── checkbox
├── span (texto)
└── button (eliminar)

3.7 - Función para Marcar como Completada

/**
 * Cambia el estado de completada de una tarea
 * @param {number} id - ID de la tarea
 */
function toggleCompletada(id) {
  // Buscar la tarea en el array
  const tarea = tareas.find(t => t.id === id);

  // Si la encontramos, cambiar su estado
  if (tarea) {
    tarea.completada = !tarea.completada;
    guardarEnLocalStorage();
    renderizarTareas();
    actualizarContador();
  }
}

Explicación:

  • find() busca la tarea que tiene ese ID
  • !tarea.completada invierte el valor (true → false, false → true)
  • Guardamos, renderizamos y actualizamos contador

3.8 - Función para Eliminar Tarea

/**
 * Elimina una tarea del array
 * @param {number} id - ID de la tarea
 */
function eliminarTarea(id) {
  // Filtrar el array excluyendo la tarea con ese ID
  tareas = tareas.filter(t => t.id !== id);

  guardarEnLocalStorage();
  renderizarTareas();
  actualizarContador();
}

/**
 * Edita una tarea existente
 * @param {number} id - ID de la tarea
 */
function editarTarea(id) {
  // Buscar la tarea en el array
  const tarea = tareas.find(t => t.id === id);

  if (!tarea) return;

  // Pedir nuevo texto
  const nuevoTexto = prompt('Editar tarea:', tarea.texto);

  if (nuevoTexto === null) return; // Usuario canceló

  const textoLimpio = nuevoTexto.trim();

  if (textoLimpio === '') {
    alert('El texto no puede estar vacío');
    return;
  }

  // Pedir nueva prioridad
  const prioridadActual = tarea.prioridad || 'media';
  const nuevaPrioridad = prompt('Nueva prioridad (alta/media/baja):', prioridadActual);

  if (nuevaPrioridad === null) return; // Usuario canceló

  const prioridadLimpia = nuevaPrioridad.toLowerCase().trim();

  // Validar prioridad
  if (!['alta', 'media', 'baja'].includes(prioridadLimpia)) {
    alert('Prioridad debe ser: alta, media o baja');
    return;
  }

  // Actualizar la tarea
  tarea.texto = textoLimpio;
  tarea.prioridad = prioridadLimpia;

  // Guardar y actualizar
  guardarEnLocalStorage();
  renderizarTareas();
}

Explicación:

  • filter() crea un nuevo array sin la tarea que tiene ese ID
  • !== significa "diferente de"
  • Guardamos todas las tareas EXCEPTO la que queremos eliminar

3.9 - Función para Filtrar Tareas

/**
 * Filtra las tareas según el filtro actual
 * @returns {array} - Tareas filtradas
 */
function filtrarTareas() {
  if (filtroActual === 'activas') {
    return tareas.filter(t => !t.completada);
  } else if (filtroActual === 'completadas') {
    return tareas.filter(t => t.completada);
  } else {
    return tareas;
  }
}

Explicación:

  • Si es 'completadas', devuelve solo las completadas
  • Si es 'todas', devuelve todo el array

3.12 - Funciones de LocalStorage

// ============================================
// LOCAL STORAGE - PERSISTENCIA DE DATOS
// ============================================

/**
 * Guarda las tareas en LocalStorage
 */
function guardarEnLocalStorage() {
  localStorage.setItem('tareas', JSON.stringify(tareas));
}

/**
 * Carga las tareas desde LocalStorage
 */
function cargarDesdeLocalStorage() {
  const tareasGuardadas = localStorage.getItem('tareas');

  if (tareasGuardadas) {
    tareas = JSON.parse(tareasGuardadas);

    // Migrar tareas antiguas que no tienen prioridad
    tareas = tareas.map(tarea => {
      if (!tarea.prioridad) {
        tarea.prioridad = 'media';
      }
      if (!tarea.fechaCreacion) {
        tarea.fechaCreacion = new Date().toISOString();
      }
      return tarea;
    });

    // Guardar las tareas migradas
    guardarEnLocalStorage();
  }
}

Explicación:

  • localStorage es como una base de datos del navegador
  • JSON.stringify() convierte el array a texto
  • JSON.parse() convierte el texto de vuelta a array
  • Los datos persisten aunque cierres el navegador

  • Cargamos datos del LocalStorage
  • Renderizamos y actualizamos

  guardarEnLocalStorage();
  renderizarTareas();
  actualizarContador();

function renderizarTareas() {
  listaTareas.innerHTML = '';
  const tareasFiltradas = filtrarTareas();

  if (tareasFiltradas.length === 0) {
    listaTareas.innerHTML = '<li style="text-align: center; padding: 20px; color: #999;">No hay tareas aquí 😊</li>';
    return;

  tareasFiltradas.forEach(tarea => {
    const li = crearElementoTarea(tarea);
    listaTareas.appendChild(li);
  });
}

function crearElementoTarea(tarea) {
  const li = document.createElement('li');
  li.className = 'tarea';

  if (tarea.completada) {
    li.classList.add('completada');
  }

  const checkbox = document.createElement('input');
  checkbox.type = 'checkbox';
  checkbox.checked = tarea.completada;
  checkbox.addEventListener('change', function() {
    toggleCompletada(tarea.id);
  });

  const span = document.createElement('span');
  span.className = 'tarea-texto';
  span.textContent = tarea.texto;

  btnEliminar.className = 'btn-eliminar';
  btnEliminar.textContent = 'Eliminar';

  li.appendChild(span);

}

Solución de Problemas Comunes

Problema 1: Error "Cannot read properties of undefined (reading 'toUpperCase')"

Causa: Las tareas antiguas en LocalStorage no tienen la propiedad prioridad Solución:

// En crearElementoTarea(), usar valor por defecto:
const prioridad = tarea.prioridad || 'media';

// En cargarDesdeLocalStorage(), migrar tareas antiguas:
tareas = tareas.map(tarea => {
  if (!tarea.prioridad) {
    tarea.prioridad = 'media';
  }
  return tarea;
});

Problema 2: No se agregan tareas

Solución:

  • Verifica que los IDs en HTML coincidan con JavaScript
  • Revisa la consola por errores
  • Asegúrate de llamar preventDefault()

Solución:

  • Verifica que guardarEnLocalStorage() se llame

Problema 4: Los filtros no funcionan
